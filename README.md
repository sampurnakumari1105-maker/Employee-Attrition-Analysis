# Employee Attrition Analysis

## Project Overview

Employee Attrition Analysis is a Data Analytics project that identifies factors associated with employees leaving an organization.

## Objectives

* Analyze employee attrition.
* Compare employees who left and those who stayed.
* Identify department-wise attrition.
* Analyze salary and employee tenure.
* Generate visual reports.

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* VS Code

## Key Analysis

1. Employee Attrition Distribution
2. Department-wise Attrition
3. Salary-wise Attrition
4. Experience-wise Attrition

## Project Outputs

* Data analysis reports
* Graphs and visualizations
* Final project report

## Conclusion

This project helps understand employee turnover patterns and identifies factors associated with employee attrition. The analysis can help organizations make better employee retention decisions.
